## 3. 对比实验和 Ablation

所有 ablation 建议围绕同一个标准配置，一次只改一个维度。

### 3.1 Topology/placement ablation

固定别的变量，inj rate 设到饱和，调整 ASPL 和 bottleneck 的 hybrid greedy 的加权，扫 $0.0,0.1,0.2,\cdots,1.0$，plot 出 throughput 以及 latency。

### 3.2 Routing ablation

固定 uniform traffic。列：考虑 hybrid greedy 和 SA，各选 2 个负载重的 inj rate。行考虑：

- mesh 上 adaptive（per-hop adaptive），express 用标准 top-8
- Static shortest route
- Random top-8 candidate
- q-only
- Express-only Dijkstra
- 标准 routing
- Global-pressure Dijkstra oracle

表格里填 throughput 和 latency。

### 3.3 信息传播 ablation

只需考虑

- Instant q/r + instant reservation
- Delayed q/r + registered reservation（目前）

然后在不同的 placement 算法上，uniform，选两组 inj rate，跑一下 throughput 和 latency 即可

### 3.4 Escape/deadlock ablation

固定 greedy placement，uniform traffic，分别扫 inj rate（横轴），画：

- Escape off、on & timeout 8/16/32/64/128 的 throughput 曲线。

这个曲线对于escape off情况如果出现死锁，就直接画红叉；对于escape on来说不要因为watchdog触发就终止。

以及 escape off 时关于不同的 traffic，各自画 inj rate - completion probability 以及 inj rate - time-to-watchdog 的线。

这部分 seed 用 20 个。

## 5. 统一统计和实验规范

这是报告可信度的关键。

### 5.1 Seed 设计

建议明确分开：

- placement search seeds
- placement validation seeds
- final holdout seeds
- Random topology seeds
- traffic/injection seeds

例如：

```
Search: traffic seeds 1,2
Validation: seeds 3,4
Final holdout: seeds 5–8
Random topology: 20 independent layouts
```

不要用同一批 seed 搜索 topology 又报告最终性能。

### 5.2 统计方法

对固定 topology：

- 4 seeds。
- 报 mean、SD、95% CI。
- Greedy/SA 使用相同 traffic seed，报告 paired difference。

对 Random expectation：

- 至少 10 topology × 2 traffic seeds。
- topology seed 是主要独立样本。
- 报 mean、median、IQR、5/95 percentile。
- 最好使用 hierarchical bootstrap：先抽 topology，再在 topology 内抽 traffic seed。

对 watchdog failure：

- 不可直接当 throughput=0 混入平均。
- 同时报告 completion rate。
- 必要时提高 threshold 精确补跑同一 sample。
- failure 本身也应单独列出。

注意你可以选一个地方存SD, 95%之类的这些附加数据，但是主表只报mean.

### 5.3 稳态和测量长度

主结果建议：

```
20k warmup + 100k measurement
```
